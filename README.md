# ShopAPI

**ShopAPI** — учебный backend-проект REST API для интернет-магазина, разработанный на Python с использованием FastAPI.

## Возможности

- Регистрация и авторизация пользователей.
- Аутентификация с использованием JWT.
- Хеширование паролей.
- Разделение пользователей по ролям (User / Admin).
- Получение списка товаров и информации о товаре.
- Получение списка категорий и информации о категории.
- Фильтрация, поиск, сортировка и пагинация товаров.
- Валидация входящих данных и обработка ошибок.

## Технологический стек

- **Python 3.14+**
- **FastAPI** — разработка REST API.
- **Pydantic** — валидация и сериализация данных.
- **SQLAlchemy 2.x** — ORM и работа с базой данных.
- **PostgreSQL** — хранение данных.
- **JWT** — аутентификация.
- **Pytest, HTTPX** — автоматизированное тестирование API.
- **uv** — управление зависимостями и окружением.
- **Docker Compose** — конфигурация окружения.

## Документация API

Интерактивная документация доступна через Swagger UI (`/docs`).

## Статус проекта

Учебный проект в разработке. Создан для практики разработки REST API, работы с базами данных, реализации аутентификации и автоматизированного тестирования.
